# Goldzilla Trading Hub

Professional static front-end demo inspired by the supplied Goldzilla dashboard reference.

## Included
- Responsive premium black/gold dashboard
- Group 1 / Group 2 public result cards
- Daily Levels manager
- Trading Journal
- Risk calculator
- Risk/Reward calculator
- XAUUSD pips calculator
- Position size calculator
- Statistics page
- Announcements
- WhatsApp link settings
- Demo admin panel

## Demo admin
Password: `goldzilla`

Important: this password is only a front-end demo. Do not use it for a real production admin system.

## Data
This version saves data in the browser using localStorage. That means data is saved on the device/browser where it was entered, but is NOT shared with all visitors.

For public shared levels/results across all users, connect this UI to Supabase (recommended) or another database.

## GitHub Pages
Upload `index.html`, `styles.css`, and `app.js` to a repository named:
`YOUR-GITHUB-USERNAME.github.io`

Then enable GitHub Pages for the main branch.

## WhatsApp links
Open Admin Panel, unlock demo admin, paste both WhatsApp group invite links, and Save Settings.
